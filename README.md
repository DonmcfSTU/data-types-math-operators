## What the program does
`dataTypesMath.py` is a Python 3 program I wrote in IDLE. It:

1. Asks for my name and Student ID.
2. Asks for two different whole numbers and turns them into integers with `int()`. The second number can't match the first or be 0, since the program divides by it.
3. Does three calculations: multiplication, division, and subtraction.
4. Prints each result with two decimal places.
5. Uses an if/else statement to say whether the first number is larger or smaller than the second.
6. Prints my name and Student ID at the end.

## How to run
Open `dataTypesMath.py` in Python IDLE and choose **Run > Run Module**. Then answer each prompt and press Enter.
